---

## ⚠️ Mandatory Safety Rules
1. **5V USB DC Power Only:** Run all experiments using your computer's USB port (or a 9V battery via the DC barrel jack when instructed).
2. **NO 220V AC Mains:** Never connect any kit component or relay to household 220V AC power lines.
3. **Check Before Plugging In:** Always double-check that `5V (VCC)` and `GND` are not directly shorted before connecting the USB cable.

## 📥 How to Download All Codes (No Git Knowledge Needed)
1. Click the green **`<> Code`** button at the top right of this page.
2. Click **`Download ZIP`**.
3. Extract the ZIP file on your computer.
4. Open any `.ino` file using **Arduino IDE 2.x** *(Keep each `.ino` file inside its matching folder name)*.

## 🔧 Drivers & Software Setup
* **Arduino IDE 2.x:** [Download from arduino.cc](https://www.arduino.cc/en/software)
* **CH340G USB-to-Serial Driver (For Clone UNO Boards):** Download `CH341SER.EXE` from the course Telegram group resources if your board shows up under *Other devices* in Windows Device Manager.
